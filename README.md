# Зертханалық жұмыс — FlightPassenger класы

## Не істедім

Тапсырма бойынша маған "Ұшақ жолаушысы" деген нұсқа тиді. Сондықтан мен FlightPassenger
деген класс жаздым. Онда жолаушының аты, рейс нөмірі, орын нөмірі сақталады, сонымен қатар
жолаушының жүктерінің салмағы сақталады. Жүктер саны әр адамда әр түрлі болуы мүмкін
(біреуде 1 сумка, біреуде 3 сумка), сондықтан оны массив ретінде емес, `new` арқылы
динамикалық массив ретінде жасадым (`double* baggageWeights`).

Тапсырмада 4 дәріске дейінгі тақырыптарды қолдану керек еді, мен солардың барлығын
осы бір класс ішінде қолдануға тырыстым:

- инкапсуляция (get/set)
- конструктор, деструктор
- this нұсқауышы
- көшірме конструктор (deep copy)
- const объект және const әдістер
- operator= артық жүктеу
- operator== артық жүктеу

## Класс қалай құрылған

Класста мынадай өрістер бар:

- `name` — жолаушының аты (string)
- `flightNumber` — рейс нөмірі (string)
- `seatNumber` — орын нөмірі (string)
- `baggageWeights` — жүктердің салмақтары, double массив, жады `new`-мен бөлінеді
- `baggageCount` — жүктер саны (int)

Барлық өрістерді `private` етіп жасадым, сырттан оларға тікелей қатынауға болмайды,
тек get/set функциялары арқылы ғана. Мысалы, атын алу үшін `getName()`, ал жаңа ат
қою үшін `setName()` қолданылады. Осылай инкапсуляция орындалды.

## Конструктор мен деструктор туралы

Екі конструктор жаздым: біреуі параметрсіз (бос объект жасайды), екіншісі —
параметрлермен (атын, рейс нөмірін, жүктерін бірден беріп объект жасауға болады).

Деструктор керек, себебі `baggageWeights` жады `new`-мен алынған, ал оны біреу
`delete`-пен босатпаса, жады ағып кетеді (memory leak). Сондықтан деструкторда
`delete[] baggageWeights;` жаздым.

## this нұсқауышы және көшірме конструктор

`this` нұсқауышын класс ішінде параметр мен өрістің аты бірдей болған кезде
шатаспас үшін қолдандым, мысалы `this->name = name;`.

Көшірме конструктор — бұл ең маңызды бөлім, себебі динамикалық жады бар өрісті
жай ғана "=" арқылы көшірсең, екі объект бір ғана жадыны көрсетіп тұрады да,
біреуін жойғанда екіншісі де бұзылып кетеді. Сол үшін мен `copyFrom()` деген
жеке функция жасадым, ол жаңа жады бөліп алып (`new double[...]`), сосын
мәндерді сол жаңа жерге бір-бірлеп көшіреді. Осыны main.cpp-те тексердім:
көшірмеге ат өзгертсем, түпнұсқа объектінің аты өзгермей қалады — демек deep copy
дұрыс жұмыс істеп тұр.

## const туралы

`getName()`, `getFlightNumber()`, `getSeatNumber()`, `getBaggageCount()`,
`getBaggageWeight()`, `getTotalBaggageWeight()` функцияларының барлығын `const`
етіп жаздым, себебі олар объектінің ешбір өрісін өзгертпейді, тек мән қайтарады.
main.cpp-те мен арнайы `const FlightPassenger` объектісін жасап, содан осы
const функцияларды шақырып көрдім — компилятор қате бермейді, өйткені олар
да const.

## operator= және operator==

`operator=` жазғанда есте ұстаған нәрсем: егер объектіге ескі жүк массиві
болса, оны алдымен `delete[]` арқылы босату керек, содан кейін ғана жаңа
мәндерді терең көшіру керек. Сонымен қатар өзін-өзіне меншіктеп қалмас үшін
`if (this == &other)` тексерісін қостым.

`operator==` үшін тапсырмада берілген шарт бойынша жаздым: егер екі жолаушының
аты да, рейс нөмірі де бірдей болса, олар "бір адам" деп саналады (орны мен
жүктері әр түрлі болса да). Осыны main.cpp-те екі түрлі объектімен тексердім —
біреуінде аты мен рейсі бірдей болғанда true шықты, ал басқасында false шықты.

## Файлдар

- `FlightPassenger.h` — класстың құрылымы, қандай өрістер мен функциялар
  бар екені осында жазылған
- `FlightPassenger.cpp` — сол функциялардың нақты іске асырылуы
- `main.cpp` — мен осында класты тексеру үшін бірнеше объект жасадым:
  қарапайым конструктор, көшірме конструктор, operator=, operator== және
  const объект — барлығына жеке мысал бар
- `README.md` — осы файл

## Қалай іске қосуға болады

```bash
g++ -std=c++11 -Wall -o flight_test main.cpp FlightPassenger.cpp
./flight_test
```

Бағдарламаны іске қосқанда әр қадамда конструктор мен деструктордың қашан
шақырылатыны экранға шығып тұрады, сондықтан объектілердің қашан жасалып,
қашан жойылатынын көзбен көруге болады.
